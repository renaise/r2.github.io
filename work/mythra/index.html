Mythra

A protocol for summoning websites into chat

Role
Co-author
Year
2023
Medium
Research + Prototype

A proposal for language models to open live websites inside a chat.

Problem

A chat could describe a website but not use it, and plugins made developers rebuild for one company.

Process

I designed summoning, from request to working page, then the edge cases: onboarding, suggestions, maps, music, taxes.

Solution

The model writes an HTTP request; the browser runs it and renders the site in the chat. Sites describe their API in a mythra.txt.
