Renaise / Public work

Aputure

A website for a global lighting catalog

Role
Art Director + Designer
Year
2024
Medium
Website

Aputure's global website, rebuilt around the lights on set.

Problem

The site sold fixtures as spec sheets, the same in every market, and few visitors reached the cart.

Process

I built the design system while wireframing, around one question: how would a cinematographer light this page? Jonas Luebbers built it.

Solution

Cinema-ratio heroes with the lights on. One click to any section, with buy, rent, download and partner up front.

Impact

One set of templates runs every market. A new market is a translation.
