Product

A browser tool for shaping 3D objects and exporting them as embeds.

Problem

Process

I asked: could 3D feel like a modular synth? The controls work like hardware.

Solution

40 shaders, 91 parameters. Pots set amount, switches set mode, and everything exports as one embed.
